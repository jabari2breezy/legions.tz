# Legions cinematic refresh

**Concept card**

- **Idea:** proof of work should feel like evidence travelling through Dar es Salaam before it settles into clear, clickable projects.
- **Metaphor:** a moving receipt rail — the work arrives in motion, then lands as a record.
- **Signature:** the Proof of Work route is a full-viewport scroll scene where image cards travel on a shallow three-dimensional rail and resolve into a project grid.
- **Emotion:** urgent, optimistic, human.
- **Motion verb:** sweep, gather, settle.
- **Screenshot:** the teal image rail passing in front of the split “Proof of / Work” heading.

**System:** Deep ocean navy (#071b46) is the ground, pale blue (#eef4ff) is the evidence field, and electric mint (#62f0d3) marks action. DM Sans and Playfair Display remain the existing project typography. Motion uses one gentle 90ms smoothing loop for the proof rail, restrained GSAP entrances, and CSS perspective on hover. All non-essential motion is removed for reduced-motion users.

**Assumption:** the existing Airtel number is the intended WhatsApp volunteer contact. The link opens a pre-written application message and does not submit data to the previous email/Sheets API.
